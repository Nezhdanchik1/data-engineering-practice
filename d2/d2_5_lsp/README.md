## Решения и ограничения

Исходные сломанные классы в tasks.txt описаны текстом; отдельных исходников нет. Исправленные реализации включены в solution.py D2.5. BatchSink раньше усиливал предусловие (минимум 100 записей); теперь принимает любой iterable и буферизует до flush/close. Цена — count означает принятые записи, долговечность наступает после flush; память ограничена размером batch. DryRunSink нарушал постусловие int и возвращал None; теперь возвращает число проверенных записей без хранения. WarehouseSink нарушал обещанную операцию flush; теперь поддерживает безопасный no-op. Это локальная учебная модель warehouse, не настоящий внешний сервис. Контрактные тесты автоматически параметризованы по всем зарегистрированным Sink, включая D2.2 и PartitionedSink.

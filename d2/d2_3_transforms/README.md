## Решения и ограничения

Transform.apply возвращает копию dict либо None. Deduplicate сохраняет состояние между записями; reset вызывается в начале исполнения. Pipeline использует композицию источника, преобразований и sink, помещает ошибки записей в rejects с сообщением, считает строки каждого шага. Ошибки инфраструктуры при записи (OSError/ConnectionError/TimeoutError) распространяются, чтобы запуск не сообщал ложный успех.

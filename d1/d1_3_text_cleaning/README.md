## Решения и ограничения

Номера 10 цифр получают префикс 7; ведущая 8 заменяется 7. Последние цифры каждого номера сохраняются. Email проверяется fullmatch прагматичного шаблона, без претензий на весь RFC. Маскирование использует re.sub с функциями. Удаление тегов подходит только для простых доверенных описаний: regex не разбирает вложенность, комментарии, script, атрибуты с > и не является HTML-парсером или защитой от XSS.

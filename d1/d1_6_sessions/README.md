## Решения и ограничения

Сортировка выполняется по пользователю и UTC времени. Ровно 30 минут остаются в сессии; новая начинается только при большем перерыве. Полночь не разрывает сессию. Неверные события попадают в rejects. Ограничение: сортировка хранит события в памяти; для больших потоков нужен внешний sort.

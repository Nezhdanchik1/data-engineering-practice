## Решения и ограничения

Watermark даты обновляется os.replace после полного файла. Неверные имена и JSON строки журналируются; ошибка callback распространяется, watermark этого файла не меняется. Файлы читаются построчно. Это хронологический high-water mark: старые опоздавшие файлы не входят в D1.4; capstone использует отдельный журнал файлов для поздних поступлений. Callback должен обеспечивать транзакционность или идемпотентность побочных эффектов при повторе после сбоя.

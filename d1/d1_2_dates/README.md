## Решения и ограничения

Все выходные метки UTC ISO 8601. Для 01/10/2026 решение требует dayfirst: True означает 1 октября, False — 10 января; угадать намерение источника нельзя. Наивные даты используют source_tz. Для повторяющегося времени DST принят fold=0; несуществующее локальное время отклоняется. partition_path использует UTC. Данные IANA 2025b поставляются отдельно от Python-кода для Windows.


`timezones.zip` — данные часовых поясов IANA 2025b, полученные из tzdata 2025.2. Их читает стандартный zoneinfo; Python-пакет tzdata не нужен. Лицензия находится в TZDATA_LICENSE.txt. База хранится одним архивом, чтобы не создавать сотни отдельных файлов.
